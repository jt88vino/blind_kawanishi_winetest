# ブラインド川西 2026 二次試験集計

GitHub → Vercel Hobby → Neon Free の構成で公開する回答集計アプリです。独自ドメインは不要です。Vercelの `vercel.app` URLを使用します。

## 機能

- ソムリエ・ワインエキスパートのタブ、白14品種・赤18品種、生産国、2018〜2025年。
- その他飲料の選択、送信後の回答数・割合集計。
- サーバーのPostgreSQLに回答を保持。ブラウザ内だけには保存しません。
- デバイスCookieとDBの主キーにより、同じブラウザの回答は両試験を通じて1回。
- 管理画面 `/admin` で問題の追加・削除・種類変更。変更前の回答も保持します。
- 管理者ログインはサーバー側のパスワード検証と8時間の署名付きHttpOnlyセッションで保護。
- 競合した問題編集・古いフォームの送信を拒否します。

## 初回公開

1. このディレクトリをVercelのRoot Directoryに設定し、Next.jsとしてインポートします。
2. Vercel Marketplaceからこのプロジェクト専用のNeonデータベースをFreeプランで接続します。接続時の接頭辞を `NEON` にすると `NEON_DATABASE_URL` が自動登録されます。接頭辞なしの `DATABASE_URL` にも対応しています。
3. VercelのEnvironment Variablesに `ADMIN_PASSWORD`（10文字以上）と `SESSION_SECRET`（32文字以上の十分ランダムな値）を登録します。値をGitHubに保存しないでください。
4. 再デプロイします。初回アクセスで `bk_` 接頭辞のテーブルを作成します。
5. `/admin` で問題構成を設定してください。初期構成は仮設定です。

## 料金について

非商用の個人活動にVercel Hobbyを使用し、NeonもFreeプランを選択します。アクセス量・保存容量・コンピュート等の無料枠内で運用してください。自動アップグレードや有料プランを有効にしないでください。提供条件の将来の変更や無制限の無料運用は保証できません。

## 移行について

既存のChatGPT Sites版の回答DBとは別のデータベースです。既存データがある場合は新サイト公開前に移行が必要です。旧サイトと新サイトはCookieが別のため、重複回答対策はURLをまたいで引き継げません。告知に使うURLは統一してください。

## 制限

Cookie削除、別ブラウザ、別端末を使う同一人物の再回答は完全には防げません。管理用パスワードやデータベース接続情報はクライアントやリポジトリに公開しません。

## ローカル確認

`npm ci`、`.env.example` を `.env.local` にコピーして各値を設定し、`npm run dev`。公開ビルドは `npm run build`。

## 選択肢とCSV

管理画面の「共通の選択肢」で、国・品種・年・飲料を1行1件で編集できます。白・赤・その他ごとに両試験へ共通で反映されます。変更前の回答も集計に保持します。
「回答結果」の集計結果CSV・回答明細CSVから、選択中の試験を出力できます。UTF-8 BOM付き、数式として解釈される文字列を無害化し、端末Cookieは出力しません。回答明細は1回答×1問題につき1行です。

選択肢は管理画面「共通の選択肢」から白ワイン・赤ワイン・その他の飲料ごとに編集します。両試験の同種類の全問題に共通で反映されます。既存回答は保持されます。

## 集計表示・公開前のリセット
各問題に国・品種・年の組み合わせ上位3順位（同数同順位）と項目別円グラフを表示します。
管理画面の回答結果から「両試験の回答データをクリア」を選び、確認文を入力すると、全回答を bk_submission_archive に退避して通常集計から除外します。問題・選択肢は維持し、端末の再回答も可能になります。退避データの復元はDBで行います。
